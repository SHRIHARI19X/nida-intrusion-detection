  - Optimizer: Adam, Loss: MSE, Epochs Trained: 13 (EarlyStopping, best epoch: 8).
  - Best Validation Loss: 0.313887.
  - Artifact: models/autoencoder.keras (226,836 bytes).

Stage 4: Anomaly Threshold Selection
  - Methodology: 95th percentile of normal validation reconstruction errors.
  - Selected Threshold: 0.1290749317.
  - Calibration Target: ~5% expected False Positive Rate on normal baseline traffic.
  - Integrity: No test data or attack samples influenced threshold selection.
  - Artifact: results/anomaly_threshold.json (1,383 bytes).

Stage 5: Test Inference on Unseen KDDTest+
  - Test Samples: 22,544 records (transformed with preprocessor.transform only).
  - Reconstruction Error: Per-sample MSE across 77 features.
  - Check: 0 NaN, 0 Inf, 0 negative values.
